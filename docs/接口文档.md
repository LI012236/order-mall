# 接口文档

- Base URL：`http://127.0.0.1:18091`
- 鉴权：除标注「否」的接口外，均需请求头 `Authorization: Bearer <token>`
- 响应统一为：

```json
{ "code": 0, "message": "success", "data": {} }
```

| code | 含义 |
|---|---|
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / token 失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 状态冲突（库存不足、重复用户名、非法状态流转等） |
| 500 | 服务内部错误 |

---

## 一、认证

### 1. 注册

`POST /api/auth/register`　鉴权：否

```json
{ "username": "hejie", "password": "123456", "nickname": "何杰", "phone": "13800000000" }
```

| 字段 | 必填 | 规则 |
|---|---|---|
| username | 是 | 3–20 位字母、数字、下划线，唯一 |
| password | 是 | 6–32 位 |
| nickname | 否 | 默认取 username |
| phone | 否 | — |

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "8680bc7c28774648afcf7c287bd7b181",
    "user": { "id": 2, "username": "hejie", "nickname": "何杰", "phone": "13800000000", "role": "USER" }
  }
}
```

错误：400 参数不合法、409 用户名已存在。

### 2. 登录

`POST /api/auth/login`　鉴权：否

```json
{ "username": "hejie", "password": "123456" }
```

响应同注册。错误：401 用户名或密码错误。

### 3. 当前用户

`GET /api/auth/me`　鉴权：是

```json
{ "code": 0, "message": "success",
  "data": { "id": 2, "username": "hejie", "nickname": "何杰", "phone": "13800000000", "role": "USER" } }
```

### 4. 登出

`POST /api/auth/logout`　鉴权：是

让当前 token 失效，响应 `{ "logout": true }`。

## 二、商品（前台）

### 5. 商品列表

`GET /api/products?page=1&size=8&keyword=键盘&category=数码`　鉴权：否

| 参数 | 必填 | 说明 |
|---|---|---|
| page / size | 否 | 默认 1 / 10，size 最大 100 |
| keyword | 否 | 名称模糊匹配 |
| category | 否 | 精确匹配 |

只返回 `status=1`（上架）的商品，按 id 倒序。

```json
{ "code": 0, "message": "success",
  "data": { "list": [ { "id": 1, "name": "机械键盘 87 键", "category": "数码",
                        "price": 299.00, "stock": 95, "cover_url": "",
                        "description": "青轴，PBT 键帽", "status": 1, "version": 3,
                        "created_at": "2026-10-23 16:46:12", "updated_at": "2026-10-23 17:15:30" } ],
            "total": 8, "page": 1, "size": 8 } }
```

### 6. 商品详情

`GET /api/products/{id}`　鉴权：否

下架或不存在返回 404。

## 三、购物车

> 只能操作自己的数据；操作他人记录返回 403。

### 7. 购物车列表

`GET /api/cart`　鉴权：是

```json
{ "code": 0, "message": "success",
  "data": {
    "list": [ { "id": 12, "product_id": 1, "product_name": "机械键盘 87 键",
                "price": 299.00, "quantity": 2, "checked": 1, "stock": 95,
                "cover_url": "", "amount": 598.00 } ],
    "checked_quantity": 2
  } }
```

### 8. 加入购物车

`POST /api/cart`　鉴权：是

```json
{ "product_id": 1, "quantity": 1 }
```

同一商品重复加入会累加数量。错误：400 数量不合法（1–99）、404 商品不存在或下架、409 库存不足。

### 9. 修改购物车

`PUT /api/cart/{id}`　鉴权：是

```json
{ "quantity": 3, "checked": 0 }
```

两个字段都可单独传。错误：400、403 越权、409 超出库存。

### 10. 删除购物车项

`DELETE /api/cart/{id}`　鉴权：是

响应 `{ "deleted": true, "id": 12 }`。

## 四、订单

### 11. 下单

`POST /api/orders`　鉴权：是

```json
{ "request_id": "7f1c...（幂等键，可省略）",
  "receiver_name": "何杰", "receiver_phone": "13800000000",
  "receiver_address": "成都市武侯区天府大道 1 号" }
```

从**已勾选**的购物车项下单。一个事务内完成：校验库存 → 扣减 → 写订单 → 写明细快照 → 清购物车。

错误：400 参数/购物车为空、409 库存不足。

```json
{ "code": 0, "message": "success",
  "data": { "id": 66, "order_no": "SO20261023171512A1B2C3", "user_id": 2,
            "total_amount": 697.00, "status": "CREATED",
            "receiver_name": "何杰", "receiver_phone": "13800000000",
            "receiver_address": "成都市武侯区天府大道 1 号",
            "request_id": "7f1c...", "created_at": "2026-10-23 17:15:12",
            "paid_at": null, "shipped_at": null, "completed_at": null, "cancelled_at": null } }
```

**幂等**：同一 `request_id` 重复提交，返回同一订单，不会重复扣库存。

### 12. 我的订单

`GET /api/orders?page=1&size=10&status=CREATED`　鉴权：是

status 可选：`CREATED / PAID / SHIPPED / COMPLETED / CANCELLED`。

### 13. 订单详情

`GET /api/orders/{orderNo}`　鉴权：是

```json
{ "code": 0, "message": "success",
  "data": {
    "order": { "order_no": "SO...", "total_amount": 697.00, "status": "CREATED", "...": "..." },
    "items": [ { "product_id": 1, "product_name": "机械键盘 87 键",
                 "price": 299.00, "quantity": 2, "amount": 598.00 } ]
  } }
```

错误：403 查看他人订单、404 不存在。

### 14. 支付（模拟）

`POST /api/orders/{orderNo}/pay`　鉴权：是

CREATED → PAID，写 `paid_at`。错误：409 非待支付状态。

### 15. 取消订单

`POST /api/orders/{orderNo}/cancel`　鉴权：是

CREATED / PAID → CANCELLED，**回补库存**。错误：409 状态不允许。

### 16. 确认收货

`POST /api/orders/{orderNo}/confirm`　鉴权：是

SHIPPED → COMPLETED。错误：409。

### 17. 支付回调（模拟第三方）

`POST /api/pay/callback`　鉴权：否（靠验签）

```json
{ "order_no": "SO...", "trade_no": "TRADE123", "sign": "sha256(order_no|trade_no|secret)" }
```

- 验签规则：`sha256(order_no + "|" + trade_no + "|" + mall-pay-secret-2026)`
- 幂等：已支付、已发货、已完成直接返回成功；已取消返回 409
- 错误：400 验签失败、404 订单不存在

## 五、后台（ADMIN）

### 18. 商品管理列表

`GET /api/admin/products?page=1&size=10&keyword=&category=`　鉴权：ADMIN

与前台列表一致，但**包含已下架商品**。

### 19. 新增商品

`POST /api/admin/products`　鉴权：ADMIN

```json
{ "name": "测试商品", "category": "数码", "price": 99.00, "stock": 10, "description": "描述" }
```

规则：名称 1–128、分类 1–32、价格 (0, 999999]、库存 [0, 1000000]、描述 ≤ 1000。

### 20. 修改商品

`PUT /api/admin/products/{id}`　鉴权：ADMIN

入参同新增，`version` 自动 +1。

### 21. 下架商品

`DELETE /api/admin/products/{id}`　鉴权：ADMIN

软删除（`status=0`），历史订单不受影响。

### 22. 后台订单列表

`GET /api/admin/orders?page=1&size=10&status=`　鉴权：ADMIN

返回全部用户的订单。

### 23. 发货

`PUT /api/admin/orders/{orderNo}/ship`　鉴权：ADMIN

PAID → SHIPPED，写 `shipped_at`。错误：409 非已支付状态。
