# 部署说明

## 一、环境要求

| 组件 | 版本 |
|---|---|
| JDK | 17+ |
| MySQL | 8.0+ |
| Node.js（仅构建前端） | 18+ |
| Nginx（可选，用于托管前端） | 1.20+ |

## 二、后端部署

### 1. 打包

```bash
cd backend
mvn -DskipTests package
# 产物：target/order-mall.jar
```

### 2. 准备数据库

首次启动会自动建库建表（`createDatabaseIfNotExist=true`），也可手动执行：

```bash
mysql -uroot -p < src/main/resources/schema.sql
```

### 3. 修改配置

`src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/mall_db?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8
    username: root
    password: "你的密码"
server:
  port: 18091
```

> 生产环境建议用环境变量覆盖，不要把密码写进仓库：
> `--spring.datasource.password=${DB_PASSWORD}`

### 4. 启动

```bash
java -jar order-mall.jar
# 或指定参数
java -jar order-mall.jar --server.port=8080 --spring.datasource.password=xxx
```

Windows 后台常驻：

```powershell
Start-Process java -ArgumentList '-jar','order-mall.jar' -WindowStyle Hidden
```

Linux 用 systemd：

```ini
[Unit]
Description=order-mall
After=network.target mysql.service

[Service]
User=app
WorkingDirectory=/opt/order-mall
ExecStart=/usr/bin/java -Xmx2g -jar order-mall.jar
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

## 三、前端部署

### 1. 构建

```bash
cd frontend
npm install
npm run build          # 产物在 dist/
```

### 2. Nginx 托管 + 反向代理

```nginx
server {
    listen 80;
    server_name mall.example.com;

    # 前端静态资源
    root /opt/order-mall/frontend/dist;
    index index.html;

    # 前端路由 history 模式，刷新不 404
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端接口
    location /api/ {
        proxy_pass http://127.0.0.1:18091;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 30s;
    }
}
```

### 3. 本地不装 Nginx 的临时方案

```bash
npm run dev     # 开发模式，vite 已把 /api 代理到 18091
```

## 四、上线检查清单

- [ ] `GET /api/health` 返回 `status: UP`
- [ ] 管理员账号已创建（首次启动自动生成 `admin/admin123`，**上线后立即改密码**）
- [ ] 数据库连接池上限 ≥ 应用并发（Hikari `maximum-pool-size`）
- [ ] 前端 `dist` 已部署，刷新任意路由不 404（`try_files`）
- [ ] 接口跨域：同域部署无需 CORS；分域部署需在 `WebConfig` 加白名单
- [ ] 日志目录可写，JVM 建议加 `-Xmx` 与 `-XX:+UseG1GC`
- [ ] 支付回调地址已在第三方配置（本项目为模拟，接入真实支付时替换 `PayController`）

## 五、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 启动报 `Access denied for user` | 数据库密码不对 | 改 `application.yml` |
| 启动报 `Table 'mall_db.product' doesn't exist` | 初始化脚本未执行 | 确认 `spring.sql.init.mode=always`，或手动执行 schema.sql |
| 前端刷新 404 | Nginx 没配 `try_files` | 加上 `try_files $uri $uri/ /index.html;` |
| 前端请求 502 | 后端没起或端口不对 | 检查 18091 与代理配置 |
| 接口返回 401 | token 过期/未带 | 前端拦截器会自动跳登录 |
